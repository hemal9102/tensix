## 🏛️ Core Engineering Pillars

1. **Autonomous AI Agents & GraphRAG:**
   - Multi-agent orchestration with LangGraph, Claude 3.7, and GPT-4o.
   - GraphRAG knowledge bases, Supabase (pgvector) semantic embeddings, and FastMCP tool servers.
2. **Cloud Infrastructure, VPS & CI/CD:**
   - Oracle Cloud Infrastructure (OCI) & Plesk Linux VPS architecture.
   - Zero-downtime GitHub Actions CI/CD deploying via SSH and Docker multi-stage builds.
   - UFW firewall hardening, automated Let's Encrypt SSL/TLS renewals, and encrypted S3 backups.
3. **High-Concurrency Custom Software & SaaS:**
   - Asynchronous APIs engineered with FastAPI, Node.js, and Python.
   - Production Next.js App Router frontends with TypeScript.
   - Relational database modeling with PostgreSQL and MySQL.
4. **Search Intelligence & Discovery (GEO, AEO, SGE):**
   - Generative Engine Optimization (GEO) & Answer Engine Optimization (AEO).
   - Complete Schema.org JSON-LD graph hierarchies and machine-readable `llms.txt` / `llms-full.txt` corpus.
