## 🚀 Site Structure & Design

### 1. Light Swiss Design
- White theme (`#FFFFFF` background, `#0F172A` text, `theme-color #ffffff`) with precision typography, high-contrast badges and generous negative space.
- Consoles and SVG topology schematics are light panels with dark strokes, not dark terminals.
- Accessible navigation: mobile slide-out drawer, ARIA attributes, keyboard support.

### 2. Services Hub + One Page per Service
- **`services.html`** is the hub: a plain 6-step process (Understand the problem → Plan and fixed price → Design the screens → Build with AI tools → Review and testing → Launch and hand-over), pricing tabs, and an `OfferCatalog` referencing each service's `@id`.

  `ai-agent-development`, `custom-software-saas-development`, `website-development`, `cloud-devops`, `email-deliverability`, `data-scraping-automation`, `geo-aeo-seo`, `fractional-cto-retainers`.

### 3. Comparison & Local Pages
- `tensix-vs-traditional-agencies.html`: plain-language comparison of a one-person studio vs a typical agency (who you talk to, fixed price, ownership), including when an agency may suit you better.
- Location pages for Navrangpura, Gota and Ahmedabad, the HK Engineering transition record (`hk-engineering-ahmedabad.html`), and 6 Ahmedabad industry guides (Textiles, Pharma, Machinery, Real Estate, Jewelry, Healthcare).

### 4. Plain Language & Honesty
- Copy is written for business owners: benefit first, jargon explained or dropped.
- No guarantees, unsourced statistics, invented testimonials or `AggregateRating`. TENSIX is presented as what it is: one person.

## 🤖 Agent Readiness

- `robots.txt` and an HTTP header send `Content-Signal: ai-train=no, search=yes, ai-input=yes`.
- The homepage sends a `Link` header to `llms.txt`, `/md/index.md`, `/.well-known/api-catalog` and `/services`.
- **Markdown negotiation:** `middleware.js` serves the `md/` mirror of any page to requests with `Accept: text/markdown`.
- Discovery files: `/.well-known/api-catalog` (RFC 9727) + `openapi.json` for `POST /api/contact`, `/.well-known/agent-skills/` (one `request-a-quote` skill), `/.well-known/ai-catalog.json`, and WebMCP attributes on the contact form.
- **Not published on purpose** (nothing real behind them): OAuth/OIDC, MCP server card, A2A card, commerce protocols, Web Bot Auth, DNS-AID SVCB records.
- DNS (Cloudflare dashboard): TXT `_catalog._agents.tensix.in` and `_catalog._agents.www.tensix.in` = `"url=https://www.tensix.in/.well-known/ai-catalog.json"`, and DNSSEC on.

## ⚡ Hosting, DNS, Build & Indexing

- **Domain & DNS:** `tensix.in` uses Cloudflare authoritative DNS (`lina.ns.cloudflare.com`, `mark.ns.cloudflare.com`), DNS-only, pointing to Vercel.
- **Routing:** `tensix.in` 308-redirects to canonical `www.tensix.in`; `cleanUrls` serves every page without `.html`.
- **Deploy allowlist:** `.vercelignore` ignores everything and re-includes only public site files. Every new public file or folder must be added there. The GitHub repo is public, so never commit private notes.
- **Build & verify (in order):**
  ```powershell
  $env:PYTHONIOENCODING="utf-8"
  python build_service_pages.py   # only if service data changed
  python build_agent_files.py     # md/ mirrors, llms.txt, llms-full.txt, sitemaps, skill digest
  python validate_schemas.py      # JSON-LD on all 45 pages, 0 errors
  python screaming_frog_audit.py  # 0 broken links, 0 orphans, canonical checks
  git add -A; git commit -m "feat: <description>"; git push origin main
  ```
- **Indexing:**
  - `submit_indexnow.py` pushes all 45 sitemap URLs to Bing, Yandex, Seznam and Naver (key file `c4b69324e9334bbba3ff6f3f02db4fb6.txt`).
  - Google: resubmit `sitemap.xml` in Search Console. `submit_google_indexing.py` exists, but Google officially supports the Indexing API only for `JobPosting` / `BroadcastEvent` pages.
