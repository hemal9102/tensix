# production-web-engineer

**Location**: `skills/production-web-engineer/SKILL.md`

## Description
Audits and optimizes web application performance, Core Web Vitals (LCP, CLS, INP), bundle sizes, render pipelines, and Next.js / React server/client rendering architecture. Use when profiling slow pages, refactoring frontend code for performance, or auditing Lighthouse/CWV scores. Do NOT use for basic HTML layout creation or backend database-only queries.
