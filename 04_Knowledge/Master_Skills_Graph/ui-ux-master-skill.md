**Location**: `skills/ui-ux-master-skill/SKILL.md`

## Description
Governs modern UI/UX design, visual aesthetics, design systems, dark modes, glassmorphism, responsive component layouts, micro-animations, and accessibility (WCAG) compliance. Use when designing web interfaces, styling UI components, establishing visual tokens, or auditing accessibility and visual polish. Do NOT use for backend database queries, API routing, or devops deployment.
