# automate-indexnow

**Location**: `skills/automate_indexnow/SKILL.md`

## Description
Automates URL submission to search engines (Bing, Yandex, Seznam, Naver) via the IndexNow protocol. Use when updating or adding website content to notify non-Google search engines instantly. Do NOT use for Google Search Console (GSC).
