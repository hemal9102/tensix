# logo-brand-guidelines

**Location**: `skills/logo-brand-guidelines/SKILL.md`

## Description
Enforces logo and brand identity standards across web UI, marketing assets, and co-branding. Covers logo variants (primary, secondary, inverse, mono), clearspace padding, size boundaries, WCAG contrast, file formats (SVG/PNG), and co-branding layout rules. Use when designing, reviewing, or implementing UI components that display brand logos. Do NOT use for general typography, CSS styling outside logos, or non-brand graphic design.
