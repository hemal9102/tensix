# ui-styling

**Location**: `skills/ui-styling/SKILL.md`

## Description
Constructs accessible user interfaces using shadcn/ui components (Radix UI + Tailwind CSS) and utility-first styling. Use when building React/Next.js frontend layouts, adding interactive components (dialogs, data tables, form validation), or implementing dark mode. Do NOT use for raw logo design or server-side API logic.
