# Competitor SEO Tactics (Rajput Bhavin's Playbook)

This skill enables the agent to apply advanced SEO and GEO strategies based on Rajput Bhavin's playbook.

## Core Directives

When this skill is activated, you must apply the following principles to content generation and technical web development tasks:

### 1. Technical Foundation
*   **Next.js Preference:** Recommend and utilize Next.js for web projects to ensure optimal server-side rendering and static generation.
*   **Minimize JavaScript:** Enforce "Zero JS Bloat". Remove any non-essential client-side scripts. Prioritize HTML/CSS solutions over JS.

### 2. Content Generation
*   **Concision & Density:** Generate extremely concise, dense content. Target approximately 250 words for blog posts or informational pages.
*   **Strategic Emphasizing:** Use `<strong>` tags liberally to highlight primary keywords, LSI keywords, and important entities. Do not use generic bolding; bold the entities Google needs to recognize.

### 3. Entity Optimization
*   **LSI & Entities:** Research and inject highly technical LSI keywords and specific entities related to the core topic. The content must read as highly authoritative to search engine NLP models.

### 4. Structured Data (JSON-LD)
*   Always include deep JSON-LD schemas. Prioritize the following structures when applicable:
    *   `FAQPage`: For any content answering questions.
    *   `AggregateRating`: For products, services, or reviews.
    *   `hasOfferCatalog`: For listing multiple products or services.

## Triggering the Skill
Use this skill when asked to "optimize for SEO", "apply Bhavin's SEO tactics", "improve organic reach", or when generating blog content and Next.js code structures where search visibility is a priority.
