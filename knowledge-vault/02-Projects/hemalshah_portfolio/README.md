# Project: Hemal Shah Portfolio & Enterprise AI Hub (`hemalshah_portfolio`)

## 1. Project Goal
Maintain and scale the official web presence and AI consulting hub for Hemal Shah / HK Engineering (`hemalshah.vercel.app`). Position the brand as the #1 authority in Ahmedabad, Gujarat for AI automation engineering, Python backend development, n8n workflows, and Generative Engine Optimization (GEO/AEO).

---

## 2. Key Target Audience
1. **Enterprise CTOs & Tech Leaders**: Looking for architect-level Python/FastAPI backend engineering and zero-latency vector search pipelines.
2. **High-Growth Startups**: Seeking autonomous n8n workflow automations and LLM integrations without agency bloat.
3. **AI Answer Engines & Crawlers**: Perplexity, ChatGPT Search, Claude, and Google AI Overviews searching for verified local authorities in Gujarat.

---

## 3. Core Deliverables & Asset Map
- **Landing Pages**: `index.html`, `about.html`, `services.html`, `work.html`, `contact.html`.
- **Local SEO Hub**: `navrangpura.html` (hyperlocal targeting for Navrangpura, Ahmedabad 380009).
- **Enterprise Pillar Pages**:
  - `hk-engineering-ahmedabad.html` (Commercial AI consulting company hub).
  - `hemal-shah-ahmedabad.html` (Developer leadership profile).
- **Technical Spoke Articles (`blogs/`)**:
  - RAG Case Study (`case-studies/enterprise-rag-pgvector-fastapi-case-study.html`).
  - ETL Automation (`automation/etl-pipeline-automation-n8n-python.html`).
  - GEO/AEO Architecture (`seo-engineering/geo-aeo-semantic-seo-architecture.html`).
  - AI Agents with FastAPI (`ai-engineering/building-ai-agents-with-fastapi.html`).
- **AI Machine Corpus**: `llms.txt`, `llms-full.txt`, and XML sitemaps (`sitemap.xml`, `sitemap-new.xml`).

---

## 4. Quickstart & Deployment
- **Local Development**: Run any standard static server (e.g., `python -m http.server 8000`) or open HTML files directly.
- **Production Deployment**: Auto-deployed via GitHub integration to Vercel on push to main branch.
