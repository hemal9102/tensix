## Description
Conducts rigorous security vulnerability reviews (OWASP Top 10, threat modeling) and Data Structures & Algorithms (DSA) performance audits (time/space complexity analysis, edge cases). Use when reviewing code for security vulnerabilities, memory leaks, or algorithmic efficiency. Do NOT use for basic UI layout styling or devops infrastructure deployment.
