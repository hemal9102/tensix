**Location**: `skills/debugging-api-data-extraction/SKILL.md`

## Description
Systematic debugging process for "silent empty data" bugs — API call succeeds (HTTP 200), database has data, but UI renders empty state. Handles double-extraction bugs, swallowed fetch errors, and envelope shape mismatches across Next.js, React, FastAPI, and Express.
