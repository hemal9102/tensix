# structured-data-validator

**Location**: `skills/structured-data-validator/SKILL.md`

## Description
Validates and fixes JSON-LD and Schema.org structured data across HTML, PHP, JS, and TS files. Use when auditing or fixing rich snippets, microdata, or JSON-LD markup. Do NOT use for standard REST API JSON schemas, relational database migrations, or general code formatting.
