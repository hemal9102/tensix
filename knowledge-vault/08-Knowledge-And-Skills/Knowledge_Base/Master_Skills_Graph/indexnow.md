# indexnow

**Location**: `skills/indexnow/SKILL.md`

## Description
Submit added, updated, or deleted web page URLs to participating search engines (Bing, Yandex, Seznam, Naver, Yep) using the IndexNow protocol for instant indexing. Use when publishing new pages, updating content, or after regenerating sitemaps. Do NOT use for Google (Google does not support IndexNow; use Google Search Console/Sitemaps for Google).
