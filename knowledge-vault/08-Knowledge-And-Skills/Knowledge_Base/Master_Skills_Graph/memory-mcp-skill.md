# memory-mcp-skill

**Location**: `skills/memory-mcp-skill/SKILL.md`

## Description
Framework for persisting durable design decisions, architectural rules, user preferences, and project gotchas across sessions into local file-based memory layers (.claude/memory and knowledge-vault/). Use after successfully implementing non-obvious architecture changes, settling design trade-offs, or establishing new project conventions. Do NOT use for transient conversation logs, temporary debug notes, or auto-generated code summaries.
