# seo-geo

**Location**: `skills/seo-geo/SKILL.md`

## Description
Optimizes web content and technical site infrastructure for Generative Engine Optimization (GEO) and AI Search Engines (Google AI Overviews, ChatGPT Search, Perplexity, Bing Copilot). Use when auditing content for AI search visibility, optimizing passage citability, configuring robots.txt for AI crawlers, or creating llms.txt. Do NOT use for basic HTML layout or non-search technical refactoring.
