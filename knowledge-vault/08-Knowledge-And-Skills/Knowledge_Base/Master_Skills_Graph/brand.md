# brand

**Location**: `skills/brand/SKILL.md`

## Description
Manages brand identity, voice guidelines, visual style guides, and design token synchronization. Use when establishing brand voice, color palettes, typography rules, or syncing brand guidelines to CSS/JSON design tokens. Do NOT use for general UI component styling or non-branded graphic generation.
