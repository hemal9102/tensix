# google-seo-docs

**Location**: `skills/google-seo-docs/SKILL.md`

## Description
Fetches and applies canonical Google Search Central SEO guidelines for audits, metadata, structured data, crawling, indexing, and internationalization. Use ONLY when auditing or implementing SEO against official Google docs. Do NOT use for automated search engine index submissions (use indexnow or gsc_instant_indexing instead).
