# obsidian-knowledge-manager

**Location**: `skills/obsidian-knowledge-manager/SKILL.md`

## Description
Framework for managing a private, structured Obsidian knowledge vault (`knowledge-vault/`) using PARA, Maps of Content (MOC), and Zettelkasten principles. Use when capturing long-term architectural decisions (ADRs), research synthesis, operational runbooks, or cross-cutting project knowledge. Do NOT use for editing active codebase files, creating transient notes, or duplicating static repository docs (`CLAUDE.md` / `ARCHITECTURE.md`).
