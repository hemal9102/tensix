# static-website-security

**Location**: `skills/static-website-security/SKILL.md`

## Description
Hardens static websites (HTML/CSS/JS on Vercel, Netlify, GitHub Pages) via SRI hashes, HTTP security headers, and CSP policies. Use when auditing or securing static frontends. Do NOT use for dynamic backend applications with SQL databases, server-rendered frameworks (Next.js/Nuxt), or API authorization testing.
