# automate-gsc-indexing

**Location**: `skills/automate_gsc_indexing/SKILL.md`

## Description
Automates URL submissions and indexing checks via Google Search Console (GSC) Web Search Indexing API. Use when publishing new pages or bulk updates needing fast Google crawling. Do NOT use for Bing, Yandex, non-GSC search engines, or routine sitemap generation.
