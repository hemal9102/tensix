# testing-and-validation-skill

**Location**: `skills/testing-and-validation-skill/SKILL.md`

## Description
Authors, executes, and validates unit, integration, and E2E test suites across backend APIs (Vitest/Pytest) and frontend UIs (Playwright/Cypress). Use when creating test suites, running automated tests, validating full-stack features, or debugging failing test assertions. Do NOT use for manual exploratory testing without code or infrastructure deployment.
