# production-engineering

**Location**: `skills/production-engineering/SKILL.md`

## Description
Audits production readiness, architecture, deployment pipelines, database migrations, security, and disaster recovery before code ships to production. Use when preparing for deployment, conducting pre-launch audits, or evaluating infrastructure PRs. Do NOT use for routine local development, UI styling tweaks, or standalone code refactoring.
