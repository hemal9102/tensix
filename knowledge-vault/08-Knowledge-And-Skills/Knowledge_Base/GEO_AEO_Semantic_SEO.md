# Generative Engine Optimization (GEO) & Answer Engine Optimization (AEO)

## 1. Concept Definition
- **AEO (Answer Engine Optimization)**: Structuring content and schemas so AI assistants (Gemini, Google AI Overviews, Siri) can extract definitive, unambiguous answers to direct user queries.
- **GEO (Generative Engine Optimization)**: Optimizing websites for generative LLM answer engines (Perplexity, ChatGPT Search, Claude) by prioritizing high information gain, semantic density, and structured citations over keyword string matching.

---

## 2. Core Engineering Pillars
1. **Semantic JSON-LD Graphs**: Layering interconnected schema types (`@graph` combining `Person`, `Organization`, `WebSite`, `Service`, `FAQPage`) with explicit `@id` URIs to eliminate entity ambiguities.
2. **High Information Gain**: Replacing fluff and keyword stuffing with original benchmarks, architecture diagrams, code snippets, and structured comparative data.
3. **Machine Knowledge Files**: Exposing website intelligence via plaintext `/llms.txt` and `/llms-full.txt` endpoints following the Entity Namespace Protocol.
4. **Hub & Spoke Architecture**: Concentrating domain authority in 2-3 Pillar Hubs supported by deeply technical, internally interlinked Spoke articles.
