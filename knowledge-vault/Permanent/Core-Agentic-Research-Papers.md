# Core Agentic Research Papers

**Purpose:** To document the academic foundation of autonomous Multi-Agent Systems (MAS).

**Summary:** True data on MAS performance is found in computer science research, not marketing blogs. These papers prove how agents can solve real-world problems autonomously when given strict Standard Operating Procedures (SOPs) and isolated environments.

## Foundational Papers
1. **SWE-agent (Princeton):** Research demonstrating how AI agents can autonomously resolve real-world GitHub issues. It highlights the importance of giving agents custom, isolated bash environments and specific tool interfaces rather than just raw CLI access.
2. **ChatDev (Tsinghua University):** Details a virtual software company where multiple agents are assigned rigid roles (CEO, CTO, Programmer, Reviewer). It proves that role-playing and sequential cross-checking drastically improve code quality over a single-agent approach.
3. **MetaGPT:** Research on how assigning rigid SOPs to agents reduces hallucinations and improves the overall architecture of the generated code. It forces agents to output structured documents (Product Requirements, System Designs) before writing code.
