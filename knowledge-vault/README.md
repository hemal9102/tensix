# JobRecruitment Knowledge Vault

Open this folder as an **Obsidian vault**. It is the project's long-term knowledge graph.

**Private & local:** gitignored (`*.md`) and rsyncignored (`knowledge-vault/`) — it never deploys to the public web root.

**Start at [[Home]]** (`00-MOC/Home.md`).

## Rules (see the `obsidian-knowledge-manager` skill)
- One note = one concept (atomic).
- Link every note to a MOC + related notes; no orphans.
- **Never duplicate** `CLAUDE.md` / `ARCHITECTURE.md` — link to them.
- Search before creating; update existing notes instead of recreating.
- Archive, don't delete.

## Folders (PARA + MOC + Zettelkasten)
`00-MOC/` maps · `Projects/` active work · `Areas/` ongoing responsibilities · `Resources/` reference · `Permanent/` atomic ideas · `Decisions/` ADRs · `Archive/` done · `Attachments/` media.
